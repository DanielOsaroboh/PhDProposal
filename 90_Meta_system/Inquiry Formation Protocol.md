# Inquiry Formation Protocol

## Function
Select, frame, and bound a knowledge problem for investigation.

## Operations
1. Select one priority knowledge problem.
2. State one central inquiry.
3. Explain inquiry context.
4. Formulate what is not understood.
5. Define in-scope and out-of-scope boundaries.
6. Define supporting sub-inquiries.
7. Specify investigation requirements.

## Output
INQ note.
