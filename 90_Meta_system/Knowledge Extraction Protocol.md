# Knowledge Extraction Protocol

## Function
Transform situated discovery into candidate transferable knowledge.

## Operations
1. Separate case-specific content from underlying structure.
2. Identify the transferable insight.
3. Calibrate the abstraction level.
4. Test the structure across multiple contexts where appropriate.
5. Identify candidate knowledge-object types.
6. Calibrate epistemic strength.
7. Route each object to Create, Enrich, or Link.

## Three-Context Transfer Test
Test whether the proposed structure can be recognised meaningfully in at least three contexts. Failure does not automatically invalidate an insight; it may indicate that the knowledge object is domain-specific.

## Output
EXT note and asset-routing decisions.
