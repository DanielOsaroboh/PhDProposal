# Knowledge Formation Pipeline

## Definition

The Knowledge Formation Pipeline is a controlled epistemic process through which raw observations and internally generated phenomena are progressively interpreted, decomposed, questioned, investigated, articulated as discoveries, and extracted for transferability before formalisation as Knowledge Assets.

## Pipeline

OBS → PIA → DECOMP → INQ → INV → DISC → EXT → KA

## Stage Logic

- **OBS captures complexity.**
- **PIA gives complexity a provisional interpretation.**
- **DECOMP exposes internal structure.**
- **INQ chooses what deserves understanding.**
- **INV performs evidence-seeking and testing.**
- **DISC records what became newly visible.**
- **EXT separates the transferable from the situated.**
- **KA formalises reusable knowledge.**

## Architectural Boundary

KA is the destination and output class, not technically a processing stage.

The formal processing pipeline is:

**OBS → PIA → DECOMP → INQ → INV → DISC → EXT**

Extraction then performs:

**CREATE → ENRICH → LINK**

against the Knowledge Asset architecture.
