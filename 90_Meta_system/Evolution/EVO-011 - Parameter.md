## Why this is a Parameter

A useful distinction in your ontology is:

|Type|Description|Example|
|---|---|---|
|**Variable**|Measured or observed in the real system|Pressure, Temperature, Salinity|
|**Parameter**|Set or configured before or during a model, experiment, or process|Learning Rate, Tree Depth, Number of Trees|
|**Metric**|Used to evaluate performance|RMSE, MAE, R²|

This separation aligns with scientific experimentation and machine learning practice, making your knowledge base more precise and easier to navigate.


I recommend creating a new ontology folder:

```
12_Parameters
    Learning Rate
    Tree Depth
    Number of Trees
    Batch Size
    Epochs
    Regularisation Parameter
    Kernel Function
```
