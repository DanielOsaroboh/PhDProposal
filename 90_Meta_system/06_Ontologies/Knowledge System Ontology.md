# Knowledge System Ontology

## Core Relationships

- Observation **IS INTERPRETED BY** Preliminary Interpretive Analysis.
- Preliminary Interpretive Analysis **IS OPENED BY** Decomposition.
- Decomposition **GENERATES CANDIDATE** Questions, Claims, Assumptions, Tensions, and Mechanisms.
- Inquiry **SELECTS AND BOUNDS** a Knowledge Problem.
- Inquiry **IS EXAMINED BY** Investigation.
- Investigation **PRODUCES** Findings.
- Findings **SUPPORT** Discovery.
- Discovery **CHANGES OR CLARIFIES** a Mental Model.
- Discovery **IS PROCESSED BY** Knowledge Extraction.
- Knowledge Extraction **IDENTIFIES** Transferable Knowledge Objects.
- Knowledge Extraction **ROUTES** Create, Enrich, or Link actions.
- Knowledge Object **IS FORMALISED AS** a Knowledge Asset.
- Knowledge Asset **SUPPORTS** Application Assets.
- Knowledge Asset **CAN BE EXPRESSED AS** Output Assets.
- Meta-System Assets **GOVERN** the ecosystem.
