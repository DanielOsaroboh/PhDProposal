# THK-0115 - Evidence-Constrained Modelling Scope

## Principle

The scope of predictive modelling should be constrained by the physical
evidence available in the compiled dataset.

## Core Idea

The research should not force the available data to support a
predetermined modelling ambition.

Instead:

```text
Available Physical Evidence
        ↓
Dataset Adequacy
        ↓
Supported Analytical Scope
        ↓
Model Selection
        ↓
Engineering Claims
```

## Opposing Logic

The principle rejects:

```
Predetermined Complex Model
        ↓
Force Available Data into Model
        ↓
Overextended Claims
```

## Scope Dimensions

Available evidence may determine:

- which variables can be included;
- which outputs can be predicted;
- which formulations can be compared;
- which HPHT ranges can be evaluated;
- which models can be justified;
- where uncertainty can be meaningfully estimated;
- how broad the engineering interpretation can be.

## Adaptive Scope

If dataset adequacy is limited, the modelling scope should contract.

If additional high-quality evidence becomes available, the modelling  
scope may expand where justified.

Thus:

```
Evidence Changes
        ↓
Scope Adapts
```

## Relationship to Scientific Modesty

Restricting scope is not necessarily a methodological weakness.

A narrower model supported strongly by physical evidence can provide  
greater scientific value than a broader model whose claims extend  
beyond the available data.

## Relationship to Extrapolation

This principle also constrains how predictions outside the supported  
domain should be interpreted.

See:

- [[THK-0096 - Interpolation–Extrapolation Validation Distinction]]
- [[THK-0099 - Epistemic Uncertainty in Foam Prediction]]

## Relationship to Operating Windows

The same principle applies downstream.

An operating window should not extend confidently into regions where  
the available evidence and predictive reliability are insufficient.

Therefore:

Evidence-Constrained Model  
↓  
Reliability-Constrained Prediction  
↓  
Uncertainty-Bounded Operating Window

## Research Significance

This principle gives the methodology an important scientific boundary:

> **The strength and breadth of the research claims must remain  
> proportional to the strength and breadth of the available physical  
> evidence.**
