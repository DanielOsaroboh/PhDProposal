# Definition

Machine Learning is a branch of artificial intelligence that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every task.

# Explanation

Machine learning develops models using historical data. These models identify relationships between variables and generalise those relationships to new observations.

# Characteristics

- Data-driven
- Learns from examples
- Improves with additional data
- Produces predictive models

# Importance

Machine learning enables engineers to predict complex behaviours where analytical equations are difficult or impossible to derive.

# Relationships

- Supervised Learning
