# Definition

Engineering Decision Support is the function of providing engineers with information, predictions, and analyses that improve technical decision-making.

# Purpose

Support informed engineering decisions by combining data, models, and domain expertise.

# Inputs

- Experimental data
- Predictive models
- Uncertainty estimates

# Outputs

- Recommendations
- Risk assessments
- Operating windows

# Importance

Improves safety, efficiency, and reliability while reducing uncertainty in engineering practice.

# Applications

- Hydraulic fracturing
- Reservoir management
- Process optimisation
- Infrastructure design
