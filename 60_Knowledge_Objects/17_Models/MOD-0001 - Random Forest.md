# Definition

Random Forest is an ensemble machine learning model that combines many decision trees to improve prediction accuracy and reduce overfitting.

# Purpose

Generate robust predictions from complex datasets.

# Inputs

- Feature matrix
- Training labels

# Outputs

- Predicted values
- Feature importance

# Assumptions

- Training data is representative.
- Multiple trees reduce variance.

# Strengths

- High predictive accuracy
- Handles nonlinear relationships
- Resistant to overfitting

# Limitations

- Less interpretable
- Computationally intensive

# Applications

- Foam rheology prediction
- Classification
- Regression
