# Definition

XGBoost is a gradient-boosting model that builds decision trees sequentially, with each tree correcting the errors of previous trees.

# Purpose

Produce highly accurate predictive models.

# Inputs

- Training dataset

# Outputs

- Predictions
- Feature importance

# Strengths

- Very high accuracy
- Handles missing values
- Fast implementation

# Limitations

- Hyperparameter tuning required
- Can overfit if poorly configured

# Applications

- Engineering prediction
- Credit scoring
- Medical diagnosis
