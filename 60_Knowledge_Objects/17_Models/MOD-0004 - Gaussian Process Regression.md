# Definition

Gaussian Process Regression (GPR) is a probabilistic machine learning model that predicts both values and their associated uncertainty.

# Purpose

Predict outputs while quantifying uncertainty.

# Inputs

- Training data
- Kernel function

# Outputs

- Prediction
- Confidence interval

# Strengths

- Provides uncertainty estimates
- Excellent for small datasets

# Limitations

- Computationally expensive
- Limited scalability

# Applications

- Bayesian optimisation
- Engineering prediction
