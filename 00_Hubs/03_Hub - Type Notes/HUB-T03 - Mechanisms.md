# HUB-T03 - Mechanisms

## Purpose

This HUB collects knowledge objects that answer:

> **How or why does something happen?**

A mechanism represents a causal process connecting an initiating condition to an observed outcome.

## Mechanism Pattern

```text
Input / Trigger
        ↓
Interaction
        ↓
Intermediate Change
        ↓
System Response
        ↓
Observed Outcome
```
