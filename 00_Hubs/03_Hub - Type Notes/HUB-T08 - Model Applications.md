# HUB-T08 - Model Applications

## Purpose

This HUB collects knowledge objects that answer:

> **How is a particular model applied to this problem?**

A model application connects a general modelling technique to a specific domain prediction problem.

## Model Application Pattern

```text
Domain Problem
        ↓
Selected Model
        ↓
Domain Inputs
        ↓
Training / Calibration
        ↓
Prediction + Evaluation
```
