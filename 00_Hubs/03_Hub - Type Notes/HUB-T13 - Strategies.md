# HUB-T13 - Strategies

## Purpose

This HUB collects knowledge objects that answer:

> **What deliberate approach can address the problem?**

A strategy is a deliberate course of action selected to address a problem or achieve a desired engineering objective.

## Strategy Pattern

```text
Problem / Need
        ↓
Strategic Choice
        ↓
Implementation Conditions
        ↓
Expected Benefit
        ↓
Trade-offs / Risks
```
