# HUB-T10 - Limitations

## Purpose

This HUB collects knowledge objects that answer:

> **Where or why does an existing approach stop working well?**

A limitation identifies a restriction in evidence, models, methods, data, assumptions, or transferability.

## Limitation Pattern

```text
Existing Approach / Evidence
        ↓
Boundary / Restriction
        ↓
Cause
        ↓
Reduced Validity / Reliability
        ↓
Mitigation Need
```
