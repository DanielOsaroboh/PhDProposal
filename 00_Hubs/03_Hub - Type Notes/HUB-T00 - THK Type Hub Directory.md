# HUB-T00 - THK Type Hub Directory

## Purpose

This note provides a single entry point into the THK knowledge base by **knowledge-object type** rather than by subject domain.

The same atomic THK note can appear in a subject HUB and a type HUB without being duplicated.

## Type HUBs

- [[HUB-T01 - Concepts]] — **What is it?**
- [[HUB-T02 - Properties]] — **What characteristic is measured or observed?**
- [[HUB-T03 - Mechanisms]] — **How or why does something happen?**
- [[HUB-T04 - Relationships]] — **How are two or more variables connected?**
- [[HUB-T05 - Thresholds]] — **At what point does behaviour change?**
- [[HUB-T06 - Models]] — **How can the phenomenon be represented mathematically or empirically?**
- [[HUB-T07 - Methods]] — **How is something investigated or predicted?**
- [[HUB-T08 - Model Applications]] — **How is a particular model applied to this problem?**
- [[HUB-T09 - Problems]] — **What is going wrong or preventing the desired outcome?**
- [[HUB-T10 - Limitations]] — **Where or why does an existing approach stop working well?**
- [[HUB-T11 - Gaps]] — **What important knowledge or capability is missing?**
- [[HUB-T12 - Failure Mechanisms]] — **How does the system lose performance or fail?**
- [[HUB-T13 - Strategies]] — **What deliberate approach can address the problem?**
- [[HUB-T14 - Engineering Functions]] — **What engineering job must the system perform?**
- [[HUB-T15 - Engineering Relationships]] — **How does a scientific or material property affect engineering performance?**
- [[HUB-T16 - Decision Processes]] — **How is evidence converted into an engineering decision?**
- [[HUB-T17 - Approaches]] — **What general way of addressing the problem is proposed?**
- [[HUB-T18 - Principles]] — **What general rule should guide interpretation or action?**
- [[HUB-T19 - Frameworks]] — **How are multiple knowledge objects integrated into a coherent system?**
- [[HUB-T20 - Systems]] — **How do interacting components collectively produce behaviour?**
