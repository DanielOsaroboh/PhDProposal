# HUB-T11 - Gaps

## Purpose

This HUB collects knowledge objects that answer:

> **What important knowledge or capability is missing?**

A gap identifies an important element that existing evidence, theory, models, methods, or practice does not adequately address.

## Gap Pattern

```text
What Is Known
        ↓
Existing Coverage
        ↓
Missing Knowledge / Capability
        ↓
Consequence
        ↓
Research Need
```
