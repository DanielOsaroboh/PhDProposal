# HUB-T09 - Problems

## Purpose

This HUB collects knowledge objects that answer:

> **What is going wrong or preventing the desired outcome?**

A problem describes an undesirable condition, obstacle, or unresolved difficulty requiring explanation, management, or solution.

## Problem Pattern

```text
Desired State
        ↓
Obstacle / Deficiency
        ↓
Causes / Drivers
        ↓
Consequences
        ↓
Need for Response
```
