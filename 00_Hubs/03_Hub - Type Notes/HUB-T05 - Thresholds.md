# HUB-T05 - Thresholds

## Purpose

This HUB collects knowledge objects that answer:

> **At what point does behaviour change?**

A threshold identifies a critical value, optimum, transition region, or regime boundary at which system behaviour changes.

## Threshold Pattern

```text
Lower Regime
        ↓
Increasing / Changing Response
        ↓
Critical or Optimal Region
        ↓
Regime Transition
        ↓
New / Adverse Response
```
