# HUB-T17 - Approaches

## Purpose

This HUB collects knowledge objects that answer:

> **What general way of addressing the problem is proposed?**

An approach is an organised way of addressing a problem that is broader than a single method but narrower than a complete framework.

## Approach Pattern

```text
Problem
        ↓
Guiding Idea
        ↓
Methods / Principles
        ↓
Outputs
        ↓
Problem-Addressing Value
```
