# HUB-T20 - Systems

## Purpose

This HUB collects knowledge objects that answer:

> **How do interacting components collectively produce behaviour?**

A system knowledge object represents an interacting set of components, variables, and processes whose combined behaviour cannot be understood adequately in isolation.

## System Pattern

```text
Inputs / Environment
        ↓
Interacting Components
        ↓
Coupled Processes
        ↓
System State / Behaviour
        ↓
Engineering Output
```
