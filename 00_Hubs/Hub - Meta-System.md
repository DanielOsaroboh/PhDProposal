# Meta-System Hub

> The higher-order governance layer for the knowledge ecosystem.

## Classes
- System Manuals — explain system purpose and operation.
- System Architecture — defines components, boundaries, relationships, and flows.
- Protocols — standardise recurring operations.
- Templates — standardise documentation structure.
- Taxonomies — classify system objects.
- Ontologies — define entities and relationships.
- Naming Systems — govern identification and semantic naming.
- System Reviews — evaluate and improve the system.

## Governing Question
**How should the knowledge system itself work?**
