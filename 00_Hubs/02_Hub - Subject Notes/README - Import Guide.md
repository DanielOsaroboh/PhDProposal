# Import Guide

This package is designed for Obsidian.

- `00 - HPHT Energised Foam Index.md` is the master entry point.
- `HUB-THK - Knowledge Object Types.md` defines the THK ontology.
- `HUB-01` to `HUB-06` are synthesis/navigation notes, not folders.
- `THK-0001` to `THK-0055` are atomic knowledge notes.
- Wikilinks assume all notes are available within the same Obsidian vault; they do not require physical subfolders.

The notes were developed from the background text supplied in the conversation. Citations are retained in author-year form from that text and should be verified against the original publications before formal academic reuse.
