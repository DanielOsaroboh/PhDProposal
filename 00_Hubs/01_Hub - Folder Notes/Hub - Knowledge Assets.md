# Knowledge Assets Hub

> Formalised, reusable units of understanding.

| Class | Primary Role | Core Question |
|---|---|---|
| Theory | Explain | Why or how does the phenomenon occur? |
| Principle | Govern | What should guide judgment or action? |
| Meta-Framework | Select/coordinate | Which framework should govern? |
| Framework | Organise | How should the elements be organised? |
| Concept | Name/compress | What is this thing or idea? |
| Mechanism | Generate/explain | How does X contribute to Y? |
| Model | Represent | How can the phenomenon be simplified usefully? |
| Pattern | Capture recurrence | What tends to recur? |
| Process | Sequence | What happens in what order? |
| Method | Provide approach | How should the task be systematically performed? |
| Technique | Enable execution | What specific action helps execute the task? |
| Distinction | Separate | What related things must not be treated as identical? |

## Asset Rule
A Knowledge Asset should be identifiable, defined, reusable, linked to provenance, and explicit about epistemic status.
